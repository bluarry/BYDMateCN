# BYDMateCN v1.0.1.1

这是 BYDMateCN 的预发布测试版本。

## 本版特性

- 工具列表支持长按拖拽排序，并持久保存自定义顺序。
- 自动化仅保留“工具”页面入口，减少重复入口。
- 功能性配置统一迁移到“工具”，设置页仅保留应用自身配置。
- 地图源中的 Amap 统一显示为“高德地图”，继续使用原有高德瓦片与坐标转换逻辑。
- 侧边栏改用专用菜单折叠图标，不再使用返回样式箭头。
- 删除 README 中“默认中文与捐赠开关”相关说明。

## 说明

该四段版本为预发布版本，不参与应用内正式版本自动更新。车辆功能仍依赖对应 DiLink 车型、固件、系统权限及硬件支持。
