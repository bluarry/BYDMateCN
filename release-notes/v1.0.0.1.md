## BYDMateCN v1.0.0.1 · WIP
面向比亚迪 DiLink 车机的中文优先应用，fork 自 BYDMate。

### 本版特性
- **大屏工具界面**：卡片式入口、分类导航、分组操作和大尺寸按钮；相机保留大预览区。
- **本地音频**：多目录扫描、播放控制、录音与离线语音合成、车外试听与按住喊话、锁车及解锁音效配置。
- **关于信息**：本分支版本、应用 ID、WIP 标识、项目链接与原项目归属说明。
- **更新检测**：读取本项目 GitHub Releases，支持 WIP 预发布及三段、四段数字版本号；统一下载安装文件名。
- **安装校验**：校验应用 ID、版本及签名；versionCode 递增至 509，相同签名下可覆盖旧版并保留应用数据。

车机专用能力依赖车型、固件、权限与硬件；WIP 版本需自愿驻车测试并反馈问题与日志。

### 发布文件
- `BYDMateCN.apk`：固定发布密钥签名的安装包。
- `BYDMateCN.apk.sha256`：安装包 SHA-256 校验文件。
