# BYDMateCN v1.0.1.4

这是 BYDMateCN 的预发布测试版本。

## 本版特性

- 新增独立的“保持 ADB 打开”开关，不改变原有“重启后恢复 ADB”功能及其配置。
- 在 ADB 可连接时初始化受限的 Shell Helper，用于重新启用车机固件的无线 ADB 开关。
- 增加 ADB 状态后台巡检；检测到经典 TCP 5555 端口不可用时，尝试重新触发车机无线 ADB。
- 保留原有 Wi-Fi/TLS 恢复流程，固件保持方案不可用时可继续按原配置执行恢复。
- 完善 ADB 恢复状态、失败原因及关键操作日志，便于实车验证和问题定位。
- 重构 ADB 恢复流程的内部结构，保持原有执行顺序与行为，并通过 Detekt 代码规范检查。

## 使用说明

首次启用“保持 ADB 打开”时，需要确保车机 ADB 当前可连接，以便启动具有 Shell 身份的辅助进程。普通应用 UID 无法直接修改车机私有系统属性，因此未完成首次初始化时，该功能可能无法恢复已关闭的 ADB。

## 说明

该四段版本为预发布版本，不参与应用内正式版本自动更新。ADB 保持能力依赖具体 DiLink 固件中的无线 ADB 属性和 Shell 权限实现，需要在目标车机上进行实车验证。
