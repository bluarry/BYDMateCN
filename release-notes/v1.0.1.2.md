# BYDMateCN v1.0.1.2

这是 BYDMateCN 的预发布测试版本。

## 本版特性

- 新增本地行车记录仪与驻车哨兵模式的初版能力及对应配置。
- 优化摄像头共享机制，电子后视镜、预览与记录功能可复用原厂 AVM 画面，减少相机抢占和重复开启。
- 增强摄像头会话仲裁、异常恢复、帧源切换及录像事件保护。
- 调整工具与设置页面布局：设置恢复独立页面，工具页面仅保留车辆功能入口。
- 修复摄像头帧处理相关编译和代码规范检查问题。

## 说明

该四段版本为预发布版本，不参与应用内正式版本自动更新。行车记录仪、驻车哨兵和摄像头共享能力仍需在对应 DiLink 车型及固件上进行实车验证。
