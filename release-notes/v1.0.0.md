## BYDMateCN · WIP
面向比亚迪 DiLink 车机的中文优先应用，fork 自 BYDMate。

### 主要特性
- **行程与能耗**：GPS 路线、距离与速度、能耗与停车消耗、行程费用和周期统计。
- **混动与充电**：电量、燃油与续航数据，充电记录及 AC/DC 统计。
- **车辆状态与自动化**：实时车辆读数，参数、时间、地点和按键触发规则，动作日志与规则导入导出。
- **多屏与电子后视**：仪表投射、中控分屏、多窗口、悬浮组件；电子后视入口复用转向联动盲区显示。
- **本地音频**：音频导入、播放控制、音量与循环、输出设备选择、LRC 歌词同步、AAC 录音、本地 TTS 与 WAV 导出。
- **车外音频与锁车音效**：固件音频路由、车外试听、按住喊话，以及人工布防的锁车/解锁音效。
- **相机与录像**：驻车 AVM 预览、JPEG 截图、截图序列导出、无音轨 MP4 分段录像、事件保护与相册管理。
- **本地媒体与诊断**：媒体 ZIP 备份恢复、存储配额管理、固件与权限只读检测、滚动文件日志及报告导出。
- **中文优先**：默认简体中文，支持手动切换语言；捐赠入口默认隐藏。

车机专用能力依赖车型、固件、权限与硬件；WIP 版本未完成全面实车验证。

### 发布文件
- `BYDMateCN.apk`：固定发布密钥签名的安装包。
- `BYDMateCN.apk.sha256`：安装包 SHA-256 校验文件。
