# BYDMateCN v1.0.1.5

这是 BYDMateCN 的预发布测试版本。

## 本版特性

- 统一车机工具详情页布局，车外音频、电子后视镜、行车记录仪和驻车哨兵采用带侧边导航的宽屏界面。
- 配置操作改为点击整行执行，移除重复的“执行”按钮，扩大车机触控区域。
- 删除设置中的旧盲区配置界面，仅保留独立的电子后视镜配置入口；移除多余的“转向联动”页签展示，不改变已有转向灯联动逻辑。
- 将车辆显示、电池与充电、固件与权限恢复到“设置”，精简“工具”列表中的重复入口。
- 完成智能家居配置界面的中文说明，明确其服务地址、密钥和场景轮询用途。
- 重构行车记录仪与驻车哨兵的存储、视角预览和录像回看布局，充分利用横屏空间。
- 录像库改为原车记录仪风格：选中录像大画面预览、多列缩略图、保护状态，以及播放、导出和删除操作。
- 自动化页面增加返回按钮，补齐独立功能页的返回路径。
- 修复录像缩略图异步加载的 Compose Lint 问题，并补齐新增设置项的多语言资源。

## 验证建议

- 分别进入车外音频、电子后视镜、行车记录仪和驻车哨兵，确认宽屏侧边栏、分类栏与配置工作区显示正常。
- 在录像库中检查缩略图生成、录像选择、播放、保护、导出和删除。
- 检查设置中的车辆显示、电池与充电、固件与权限入口，以及自动化页面返回按钮。

## 说明

该四段版本为预发布版本，不参与应用内正式版本自动更新。摄像头、录像与车辆联动能力仍需在目标 DiLink 车机上进行实车验证。
