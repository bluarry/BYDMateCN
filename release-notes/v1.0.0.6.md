# BYDMateCN 1.0.0.6

- 修复车机未向应用 UID 授予 `BYDAUTO_AUDIO_SET` 时，车外音频通道直接调用被固件拒绝的问题。
- 车外试听、实时喊话和锁车/解锁音效改由现有高权限 helper 发送固定的车外通道指令，并记录 autoservice 原始返回状态。
- 保持 23 控制器使用旧式音频流 15、非 23 控制器使用旧式音频流 3，不降级为普通车内媒体播放。
- 移除可信蓝牙设备自动解锁功能、配置入口、连接广播监听和专用蓝牙权限。
- 主应用左侧导航缩窄，并新增可持久化的折叠/展开状态。
- 工具详情页的功能分类栏同步缩窄，支持折叠为紧凑索引。
