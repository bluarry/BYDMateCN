# BYDMateCN v1.0.0.9

- 修复行车自动落锁误触发锁车音效：新增挡位、车速与电源状态判定。
- 门锁音效观察服务在高权限助手失联时自动恢复，改善长时间停车后解锁音效失效。
- 车外试听改用车身控制器驻车状态直读，并区分页面离开、行车状态与助手不可用。
- 车外路由优先使用高权限助手；助手失联时尝试车机 `auto` 服务并完整记录结果。
- 内部数据库和备份名称切换为 BYDMateCN，升级时自动迁移已有数据，仍兼容旧备份。
- 清理中文界面中的旧产品名，保留 Fork 来源说明。

- 将高权限助手的进程锁和日志标签完全切换为 BYDMateCN，避免与原版助手冲突并导致长时间运行后失联。
- 车外试听无法建立专用路由或无法读取驻车状态时，改用标准媒体属性进行普通媒体降级播放。
- 原“日志记录”导出现在同时包含锁车音效、车外路由和本地音频验证日志，便于直接回传定位。
