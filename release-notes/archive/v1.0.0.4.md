## BYDMateCN v1.0.0.4

面向比亚迪 DiLink 车机应用，提供行程能耗、车辆状态、自动化、多屏与盲区显示(电子后视镜)、解锁车音效、哨兵模式等。需启用并授权 ADB 的功能包括：实时车辆数据、车窗与空调等车辆控制、自动化车辆动作、分屏与多窗口、仪表投屏与 HUD、方向盘按键、盲区显示(电子后视镜)、车外喊话、锁车/解锁音效、哨兵模式及车辆诊断。Fork 自 BYDMate。

### 本版特性
- 车外音频改用 DiLink `auto` 系统服务的反射调用方式控制车外功放。
- 支持 23 控制器与非 23 控制器两种车外音频配置，并匹配对应音频流。
- 完善车外试听、按住喊话、锁车及解锁音效的会话互斥、停止与异常恢复。
- 补充 DiLink 车机私有权限声明，覆盖音频、ADAS、全景影像、电子后视镜及车辆状态等能力域。
- 改进本地音频、麦克风转发与相机预览的状态处理和日志记录。
