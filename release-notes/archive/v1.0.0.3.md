## BYDMateCN v1.0.0.3

面向比亚迪 DiLink 车机应用，提供行程能耗、车辆状态、自动化、多屏与盲区显示(电子后视镜)、解锁车音效、哨兵模式等。需启用并授权 ADB 的功能包括：实时车辆数据、车窗与空调等车辆控制、自动化车辆动作、分屏与多窗口、仪表投屏与 HUD、方向盘按键、盲区显示(电子后视镜)、车外喊话、锁车/解锁音效、哨兵模式及车辆诊断。Fork 自 BYDMate。

### 本版特性
- 精简工具页面，仅保留已有实现入口。
- 调整大屏工具布局和独立配置页面。
- 本地日志、备份及应用数据使用 BYDMateCN 独立空间。
- 车外音频接入固件功放开关，并增加停止、异常回滚和会话互斥处理。
- 本地音频支持多目录扫描、播放、录音、离线语音及锁车/解锁声音配置。

### 发布文件
- `BYDMateCN-1.0.0.3.apk`：固定发布密钥签名的安装包。
