## BYDMateCN v1.0.0.1
面向比亚迪 DiLink 车机应用，提供行程能耗、车辆状态、自动化、多屏与盲区显示(电子后视镜)、解锁车音效、哨兵模式等。需启用并授权 ADB 的功能包括：实时车辆数据、车窗与空调等车辆控制、自动化车辆动作、分屏与多窗口、仪表投屏与 HUD、方向盘按键、盲区显示(电子后视镜)、车外喊话、锁车/解锁音效、哨兵模式及车辆诊断。Fork 自 BYDMate。

### 本版特性
- **大屏工具界面**：卡片式入口、分类导航、分组操作和大尺寸按钮；相机保留大预览区。
- **本地音频**：多目录扫描、播放控制、录音与离线语音合成、车外试听与按住喊话、锁车及解锁音效配置。
- **关于信息**：本分支版本、应用 ID、版本信息、项目链接与原项目归属说明。
- **更新检测**：读取本项目 GitHub Releases，支持预发布及三段、四段数字版本号；统一下载安装文件名。
- **安装校验**：校验应用 ID、版本及签名；versionCode 递增至 509，相同签名下可覆盖旧版并保留应用数据。

车机专用能力依赖车型、固件、权限与硬件；请在安全驻车状态下配置车辆相关功能。

### 发布文件
- `BYDMateCN.apk`：固定发布密钥签名的安装包。
- `BYDMateCN.apk.sha256`：安装包 SHA-256 校验文件。
