# BYDMateCN v1.0.1

这是 BYDMateCN 的正式版本。

## 本版特性

- 重构工具页面及功能详情页，统一导航、卡片、字体、间距和宽屏/分屏布局。
- 将车辆功能配置与自动化入口集中到“工具”，减少重复入口并保留原有控制逻辑。
- 工具列表支持长按拖拽排序，并持久保存自定义顺序。
- 电子后视镜新增“转向灯亮期间持续显示”，避免画面随转向灯闪烁间隔关闭。
- 电子后视镜新增可配置的延迟关闭，支持 0–5 秒、0.5 秒步进，默认 1.5 秒。
- 电子后视镜在左右转向切换时立即切换画面；倒挡、原厂 360、遥测异常或不满足速度条件时仍立即安全关闭。
- 改进窄窗口和分屏适配，空间不足时自动调整分类导航和配置项布局。
- 修复独立包名下电子后视镜悬浮窗及投影权限的检查与修复流程。
- 完善默认中文界面、项目介绍、问题反馈模板和正式发布文案。
- 应用内自动更新仅跟踪三段式正式版本，不自动安装四段式预发布版本。

## 说明

车辆功能依赖比亚迪 DiLink 车型、固件、系统权限及对应硬件。涉及车辆控制、投屏、电子后视镜、车外音频和诊断的能力需要按项目说明启用并授权 ADB。

## 发布文件

- `BYDMateCN-1.0.1.apk`：固定发布密钥签名的安装包。
- `BYDMateCN-1.0.1.apk.sha256`：安装包 SHA-256 校验文件。
