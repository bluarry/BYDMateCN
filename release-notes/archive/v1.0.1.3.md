# BYDMateCN v1.0.1.3

这是 BYDMateCN 的预发布测试版本。

## 本版特性

- 重构车外语音配置界面，统一深色车机样式、顶部分类与配置交互。
- 新增本地音频文件预览与播放入口，优化多目录扫描和音频选择体验。
- 重构电子后视镜配置页面，在保留原有盲区显示控制逻辑的基础上统一界面布局。
- 完善行车记录仪与驻车哨兵配置，支持各自独立的录像目录、容量配额和录像列表。
- 支持行车记录与哨兵录像在应用内预览、导出、删除、保护和刷新。
- 增加前、后、左、右四个 AVM 视角的预览选择，并优化摄像头会话共享与录像切换流程。
- 隔离行车记录仪和驻车哨兵的存储、备份及恢复数据，避免两种模式的数据混用。
- 修复车外语音 Compose 状态在界面重组时被重建的问题，并通过代码规范和 Lint 检查。

## 说明

该四段版本为预发布版本，不参与应用内正式版本自动更新。摄像头录像、存储目录和驻车哨兵能力仍需结合对应 DiLink 车型及固件进行实车验证。
