## BYDMateCN v1.0.0.3 · WIP

面向比亚迪 DiLink 车机的中文优先应用，fork 自 BYDMate。

### 本版特性
- 精简工具页面，仅保留已有实现入口。
- 调整大屏工具布局和独立配置页面。
- 本地日志、备份及应用数据使用 BYDMateCN 独立空间。
- 车外音频接入固件功放开关，并增加停止、异常回滚和会话互斥处理。
- 本地音频支持多目录扫描、播放、录音、离线语音及锁车/解锁声音配置。

### 发布文件
- `BYDMateCN-1.0.0.3.apk`：固定发布密钥签名的安装包。
- `BYDMateCN-1.0.0.3.apk.sha256`：安装包 SHA-256 校验文件。
