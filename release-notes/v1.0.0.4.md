## BYDMateCN v1.0.0.4 · WIP

面向比亚迪 DiLink 车机的中文优先应用，fork 自 BYDMate。

### 本版特性
- 车外音频改用 DiLink `auto` 系统服务的反射调用方式控制车外功放。
- 支持 23 控制器与非 23 控制器两种车外音频配置，并匹配对应音频流。
- 完善车外试听、按住喊话、锁车及解锁音效的会话互斥、停止与异常恢复。
- 补充 DiLink 车机私有权限声明，覆盖音频、ADAS、全景影像、电子后视镜及车辆状态等能力域。
- 改进本地音频、麦克风转发与相机预览的状态处理和日志记录。

### 发布文件
- `BYDMateCN-1.0.0.4.apk`：固定发布密钥签名的安装包。
- `BYDMateCN-1.0.0.4.apk.sha256`：安装包 SHA-256 校验文件。
