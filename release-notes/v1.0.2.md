# BYDMateCN v1.0.2

## 本版特性

- 统一车机工具详情页布局，车外音频、电子后视镜、行车记录仪和驻车哨兵采用带侧边导航的横屏界面。
- 配置操作支持点击整行执行，移除重复的“执行”按钮，扩大车机触控区域。
- 设置页面仅保留独立的电子后视镜配置入口，并将车辆显示、电池与充电、固件与权限恢复到设置分类。
- 完成智能家居配置界面的中文说明，明确服务地址、API 密钥和场景轮询用途。
- 重构行车记录仪与驻车哨兵的存储、视角预览和录像回看布局，充分利用大屏空间。
- 录像库升级为大画面预览、多列缩略图和选中状态展示，支持播放、保护、导出与删除。
- 自动化页面增加返回按钮，完善独立功能页面的导航体验。
- 修复录像缩略图异步加载问题，并补齐新增设置项的多语言资源。

## 使用提示

摄像头、录像、车外音频和车辆联动能力依赖 DiLink 车机接口与权限。升级后建议分别检查电子后视镜、行车记录仪、驻车哨兵及录像回看功能。
